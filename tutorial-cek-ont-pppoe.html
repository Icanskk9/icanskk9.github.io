Cara Cek Status PPPoE Active dan Tes ONT Pelanggan

Kategori: PPPoE & Monitoring • MikroTik Hotspot Monitoring

Fitur PPPoE Active & Tes ONT memudahkan teknisi memeriksa daftar pelanggan rumahan yang sedang terhubung, melihat durasi aktif (uptime), alamat IP yang didapatkan, serta menguji respons perangkat modem/ONT di rumah pelanggan.

1. Mengaktifkan Remote Management pada ONT

Agar perangkat ONT pelanggan bisa di-ping atau diakses halaman konfigurasinya dari jaringan lokal server monitoring, pastikan opsi Enable WAN Ping dan HTTP WAN Access (atau remote port khusus) sudah diaktifkan pada pengaturan keamanan modem ONT.

2. Memantau Koneksi melalui Dashboard

  1. Buka menu PPPoE → Active pada dashboard MikroTik Hotspot Monitoring.
  2. Sistem akan menampilkan daftar akun pelanggan aktif beserta alamat IP dinamis maupun statisnya.
  3. Gunakan tombol Tes ONT di samping nama pelanggan untuk mengecek latensi koneksi atau membuka antarmuka web modem secara langsung.

Referensi konfigurasi lengkap dapat dibaca juga pada Dokumen Panduan PDF.
