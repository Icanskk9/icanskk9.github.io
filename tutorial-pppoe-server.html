Konfigurasi Dasar PPPoE Server di MikroTik untuk Jaringan Rumahan

Kategori: PPPoE Networking • MikroTik RouterOS

Untuk pelanggan internet rumahan (bulanan), protokol PPPoE (Point-to-Point Protocol over Ethernet) jauh lebih stabil dan aman dibandingkan metode DHCP biasa karena setiap pelanggan diautentikasi menggunakan username dan password unik pada ONT/router masing-masing.

1. Membuat IP Pool dan PPP Profile

/ip pool add name=pool-pppoe ranges=10.20.30.2-10.20.30.254
/ppp profile add name=paket-10mbps local-address=10.20.30.1 remote-address=pool-pppoe rate-limit=10M/10M dns-server=8.8.8.8,1.1.1.1

2. Mengaktifkan PPPoE Server & Membuat Akun (Secret)

/interface pppoe-server server add service-name=pppoe-induk interface=ether3-lokal default-profile=paket-10mbps one-session-per-host=yes disabled=no
/ppp secret add name=pelanggan01 password=rahasia123 service=pppoe profile=paket-10mbps

Pastikan opsi one-session-per-host=yes diaktifkan untuk mencegah satu akun PPPoE dipakai dial ganda dari dua rumah berbeda. Panduan manajemen PPPoE lewat dashboard tersedia di Dokumen PDF Panduan.
