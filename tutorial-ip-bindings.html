Setting Hotspot IP Bindings untuk Bypass Perangkat Tanpa Login

Kategori: Hotspot Management • MikroTik RouterOS

Perangkat seperti Access Point, CCTV, Smart TV, atau printer jaringan yang terhubung ke jaringan Hotspot tidak memiliki browser untuk memasukkan kode voucher. Untuk mengatasinya, gunakan fitur IP Bindings agar perangkat tersebut mendapat akses langsung berdasarkan MAC Address.

Jenis Tipe pada IP Bindings

  • Regular: Perangkat tetap melewati proses autentikasi halaman login hotspot seperti biasa.
  • Bypassed: Perangkat langsung mendapat akses internet tanpa perlu login voucher.
  • Blocked: Memblokir total perangkat tertentu agar tidak dapat mengakses jaringan hotspot.

Menambahkan IP Binding via Terminal

/ip hotspot ip-binding
add mac-address=AA:BB:CC:11:22:33 type=bypassed server=hotspot1 comment="AP-Lantai-1"

Kamu juga dapat menambah, mengubah status, atau menghapus daftar IP Bindings secara cepat melalui menu Hotspot → IP Bindings di dashboard monitoring. Panduan lengkap tersedia di File PDF Panduan.
