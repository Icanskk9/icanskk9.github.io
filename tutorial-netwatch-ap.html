Konfigurasi Netwatch untuk Monitoring Perangkat Access Point

Kategori: Networking • RouterOS Netwatch

Dalam pengelolaan jaringan hotspot maupun RT/RW Net, mengetahui status perangkat pemancar (Access Point) yang mati atau hang secara cepat sangat penting sebelum pelanggan melapor. MikroTik memiliki fitur bawaan bernama Netwatch yang melakukan ping berkala ke alamat IP perangkat dan otomatis terbaca oleh dashboard MikroTik Hotspot Monitoring.

1. Pastikan Setiap Access Point Memiliki IP Statis

Berikan alamat IP statis pada setiap perangkat Access Point (atau lakukan Make Static pada menu IP → DHCP Server → Leases) agar alamat IP perangkat tidak berubah-ubah saat router reboot.

2. Menambahkan Host di Menu Netwatch

  1. Buka Winbox dan masuk ke menu Tools → Netwatch.
  2. Klik tanda tambah (+) untuk membuat aturan monitoring baru.
  3. Pada kolom Host, masukkan IP statis Access Point (contoh: 192.168.10.2).
  4. Atur Interval pengecekan, misalnya 00:00:30 (setiap 30 detik) dan Timeout 1000 ms.
  5. Isi bagian Comment dengan nama lokasi atau kode AP (misalnya AP-Utara-01) agar mudah dikenali di halaman dashboard monitoring.

3. Konfigurasi via Terminal RouterOS

Untuk menambahkan banyak perangkat sekaligus dengan cepat, jalankan perintah berikut melalui New Terminal di Winbox:

/tool netwatch
add host=192.168.10.2 interval=30s timeout=1s comment="AP-Sector-Utara"
add host=192.168.10.3 interval=30s timeout=1s comment="AP-Sector-Selatan"

Setelah tersimpan, status perangkat (up atau down) beserta keterangan waktunya akan langsung tampil secara otomatis pada panel monitoring perangkat di aplikasi.
