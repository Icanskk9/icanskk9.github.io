Memantau Live Traffic Interface dan Pemakaian Bandwidth

Kategori: Monitoring Jaringan • Dashboard Utama

Grafik Live Traffic pada halaman utama MikroTik Hotspot Monitoring menampilkan arus lalu lintas data secara real-time tanpa perlu membuka Winbox secara terus-menerus.

Memilih Interface yang Dipantau

  • Masuk ke pengaturan sesi router di dashboard monitoring.
  • Pilih nama interface sumber internet (misalnya ether1-ISP) atau interface distribusi pelanggan (seperti bridge-hotspot) pada kolom Traffic Interface.
  • Grafik akan menampilkan kecepatan unggah (Tx) dan unduh (Rx) dalam satuan Kbps atau Mbps setiap detik.

Pemantauan ini membantu mendeteksi lonjakan pemakaian tidak wajar atau gangguan jalur ISP lebih dini. Penjelasan fitur dashboard lainnya tersedia di Panduan Lengkap PDF.
