Cara Backup Konfigurasi MikroTik dan Database Mikhmon

Kategori: Maintenance & Keamanan • RouterOS

Melakukan pencadangan rutin sangat penting untuk mencegah hilangnya data pelanggan PPPoE, aturan firewall, dan rekaman penjualan voucher apabila terjadi kerusakan perangkat keras atau gangguan listrik.

1. Backup Biner dan Export Script (.rsc) di MikroTik

Gunakan perintah berikut melalui Terminal untuk membuat dua jenis cadangan sekaligus (file .backup untuk pemulihan di tipe perangkat yang sama, dan .rsc untuk dipindahkan ke tipe RouterBoard berbeda):

/system backup save name=backup-rutin
/export file=config-script

Unduh kedua file tersebut dari menu Files di Winbox ke komputer lokal.

2. Mencadangkan Pengaturan Dashboard Monitoring

Salin folder include/ di dalam direktori aplikasi MikroTik Hotspot Monitoring secara berkala agar data konfigurasi sesi router dan pengaturan admin tetap aman. Selengkapnya baca pada File Panduan Lengkap (PDF).
