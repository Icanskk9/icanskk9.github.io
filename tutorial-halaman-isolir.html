Memasang Halaman Isolir Pelanggan PPPoE pada MikroTik

Kategori: Billing & PPPoE • MikroTik RouterOS

Halaman isolir berfungsi mengalihkan koneksi internet pelanggan PPPoE yang melewati masa jatuh tempo pembayaran ke halaman pemberitahuan khusus, alih-alih memutus koneksi secara total sehingga pelanggan bingung mengapa internet mati.

1. Membuat IP Pool Khusus Isolir

Buat rentang alamat IP khusus yang hanya diberikan kepada pelanggan berstatus isolir melalui menu IP → Pool:

/ip pool add name=pool-isolir ranges=172.16.99.2-172.16.99.254

2. Membuat PPP Profile Isolir

Masuk ke menu PPP → Profiles dan buat profil baru bernama isolir dengan mengarahkan Remote Address ke pool-isolir serta membatasi Rate Limit (misalnya 64k/64k).

/ppp profile add name=isolir local-address=172.16.99.1 remote-address=pool-isolir rate-limit=64k/64k

3. Mengarahkan Trafik HTTP ke Halaman Isolir

Tambahkan aturan NAT pada IP → Firewall → NAT untuk membelokkan akses browser pelanggan dari subnet 172.16.99.0/24 menuju IP server lokal tempat file halaman isolir disimpan (misalnya 192.168.1.100 port 80), lalu blokir akses internet lainnya di bagian Filter Rules:

/ip firewall nat
add chain=dstnat src-address=172.16.99.0/24 protocol=tcp dst-port=80 action=dst-nat to-addresses=192.168.1.100 to-ports=80 comment="Redirect Halaman Isolir"

/ip firewall filter
add chain=forward src-address=172.16.99.0/24 dst-address=!192.168.1.100 action=drop comment="Blokir Internet Pelanggan Isolir"

Ketika pelanggan jatuh tempo, cukup ubah profil akunnya di menu PPP → Secrets (atau langsung melalui fitur manajemen PPPoE di dashboard monitoring) menjadi isolir.
