Cara Instalasi MikroTik Hotspot Monitoring di Windows & Linux

Kategori: Panduan Instalasi • Mikhmon V3 WS Custom UI Edition

MikroTik Hotspot Monitoring (Custom UI Edition) merupakan pengembangan dari Mikhmon V3 yang dirancang untuk mempermudah manajemen voucher hotspot, pemantauan perangkat Access Point via Netwatch, serta pengecekan status pelanggan PPPoE dalam satu dashboard web.

1. Persiapan Paket Aplikasi & Web Server

  • Unduh paket lengkap aplikasi melalui repositori resmi di GitHub MikroTik-Hotspot-Monitoring (.ZIP).
  • Siapkan lingkungan web server lokal dengan dukungan PHP (minimal PHP 7.4 atau PHP 8.x), seperti XAMPP, Laragon, atau PHP Built-in Server bawaan paket.

2. Ekstrak dan Jalankan Server

  1. Ekstrak file MikroTik-Hotspot-Monitoring-main.zip ke dalam folder root web server (misalnya C:\xampp\htdocs\monitoring atau /var/www/html/monitoring).
  2. Jika menggunakan Windows tanpa XAMPP, jalankan file executable server bawaan yang tersedia di dalam folder paket.
  3. Buka browser dan akses alamat http://localhost/monitoring.

3. Login Awal & Konfigurasi API MikroTik

Pada halaman login awal, masukkan kredensial bawaan sistem:

Username : admin
Password : admin123

Segera ganti username dan password default melalui menu Admin Settings demi keamanan. Setelah itu, aktifkan layanan API pada router MikroTik melalui Winbox di menu IP → Services, pastikan port api (default 8728) dalam keadaan aktif, lalu tambahkan sesi router baru di dashboard monitoring.
