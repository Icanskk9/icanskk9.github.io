Cara Memasang Template Login Page Hotspot MikroTik

Kategori: Kustomisasi UI • Hotspot MikroTik

Mengganti tampilan bawaan halaman login hotspot MikroTik dengan template kustom membuat pelanggan lebih mudah memilih mode login (voucher atau member), melihat daftar harga paket, serta menghubungi kontak bantuan admin.

Langkah Upload Template ke Router

  1. Siapkan folder template login hotspot yang berisi file wajib seperti login.html, status.html, logout.html, dan error.html.
  2. Buka Winbox dan masuk ke menu Files.
  3. Tarik (drag and drop) folder template tersebut ke jendela Files di Winbox (perhatikan apakah berada di direktori utama / atau di dalam flash/ tergantung tipe RouterBoard).
  4. Masuk ke menu IP → Hotspot → Server Profiles, lalu klik dua kali pada profil hotspot yang aktif.
  5. Pada bagian HTML Directory, pilih nama folder template baru yang baru saja diunggah, lalu klik OK.

Uji coba dengan menghubungkan ponsel ke Wi-Fi hotspot untuk memastikan halaman login baru tampil sempurna. Unduh paket template beserta Panduan Lengkap (PDF).
